# Catalogue fixture provenance — 13 November 2026

`catalogue-demo.json` contains 35 real product models with 37 representative variants across the nine BA groups. Each record links an official Apple product/specification page retrieved through web browsing on the recorded date. Product names, selected chip/display/storage/color attributes and explicit accessory compatibility are factual references. Source pages are not copied in full.

The user's subsequent photography request is implemented with 37 locally downloaded Apple images for all 35 models, including separate Glacier/Night Sky images for the two additional color variants. `product-photos.json` records the exact source page/image, generation verification, color mapping, dimensions and SHA-256. Apple retains ownership; these files are bundled for the requested local educational demonstration, without claiming an open redistribution license. The original category SVGs remain as legacy assets, but the current catalogue uses the real product photographs.

`scripts/import-product-photos.ps1` validates the complete manifest and produces a read-only plan by default. `-Apply` runs the existing C# backend/EF connection, updates only `products.poster` and writes before/after audit records in one transaction. It refuses unexpected existing posters and is idempotent. It does not reseed products, modify prices/stock/IDs, or run migrations. The API supplies the shared color-photo metadata; Next.js has no independent product-to-image lookup. `framingScale` trims source-canvas whitespace in CSS only; source image bytes and colors are unchanged.

The selling prices, warehouse quantities, tracking policy, 12-month standard warranty policy and optional BotZone Care fees are **course-project configuration**, not statements of Apple's current prices or contractual warranty terms. `priceType` is `demo` for every product. The application must display its demo-price notice. Out-of-stock variants are intentional. The fixture does not claim every historic configuration or every current Apple product is listed.

Current and previous representatives include MacBook Air M5/M4, iPad Air M4/M3, Watch Series 12/11, AirPods Pro 3/2, Apple TV 4K A19/third generation, Vision Pro M5/M2, Studio Display 2026/2022 and AirTag second/first generation. Additional Mac mini, iPad Pro, HomePod, AirPods Max and accessory families cover the BA's named product types. iPhone generations 13–17 and 18 Pro/Pro Max plus Duo are represented.

The iPhone 18 Pro specification page lists Burgundy and Băng Thanh for Pro and Pro Max. The Duo page lists Trời Đêm and Trắng Ánh Sao. The local illustrative materials are representative values documented separately in `asset-sources.json`; they are not an official HEX extraction. Uploaded/licensed replacement photography can be managed through the content-staff media library. Bundled SVGs are original category illustrations and should not be represented as exact photographs of every model.

Historical `P13`, `P14`, `AP2` codes intentionally match the existing financial-test fixture so the single C# seed owner can reuse existing products and preserve invoice history. Canonical hero slugs are `iphone-18-pro-max` and `iphone-duo`. `compatibleSlugs` is a directed accessory-to-device relation that the C# seed imports by product IDs after inserting the catalogue. No database writes are performed by these data files.
